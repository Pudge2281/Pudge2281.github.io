ABOUT THE PROJECT

Welcome to the Blackpink AI Experience. This is a deep simulation of real-life interactions with the 4 members and plenty of NPCs for any scene (cafes, streets, fans, etc.).

First, you set up the starting situation for your meeting (e.g., a private island, airport, or fan meeting), and then the girls will send you their first messages.

Bilingual Support: The app fully supports both English and Russian. This changes not only the user interface but also the language the girls use to communicate with you!

Sympathy Bar

The girls' responses and attitudes change based on your actions and their level of sympathy towards you.

Deep Memory

Excellent long-term memory. The girls can easily remind you of a nickname or a mistake you made 20 days ago.

3 Save Slots

Run up to three different games (storylines) simultaneously without losing your progress.

Lively Stylish Chat

Each girl has her own text color. They describe actions, talk to each other, and react to your messages together.

HOW TO START

Follow these steps to get the AI game running on your Android device:

# 1. Get an API Key

Create a key in Google API: aistudio.google.com

# 2. Download the Game

Download and install the game's APK file on your Android.

# 3. Enter the Key

Launch the game, copy your API key, and paste it into the settings.

Important: The Android app does not collect or send your key information to anyone. Your key is stored securely and locally on your device, used solely for direct communication with the AI.
