B-PINK AI ADVENTURE

О ПРОЕКТЕ

Добро пожаловать в Blackpink AI Experience. Это интерактивное текстовое приключение с открытым исходным кодом, созданное для BLINK и энтузиастов ИИ.

Игра позволяет вам проходить уникальные сюжетные линии, симулировать закулисную подготовку к концертам и взаимодействовать с динамичными ИИ-персонажами Джису, Дженни, Розэ и Лисы.

Интерактивный сюжет

Формируйте историю своими решениями. Каждое прохождение уникально.

Динамичный ИИ

Генерация ответов в реальном времени делает каждый диалог живым.

КАК НАЧАТЬ

Выполните эти шаги для запуска игры локально:

# 1. Клонировать репозиторий

git clone https://github.com/yourusername/bp-ai-game.git

# 2. Установить зависимости

cd bp-ai-game

npm install

# 3. Добавить API ключ ИИ в .env

VITE_AI_API_KEY="ваш_ключ_api"

# 4. Запустить сервер разработки

npm run dev

ПЛЮСЫ И МИНУСЫ

Плюсы

  • ✦Глубокое погружение и персонализированные сюжеты.
  • ✦Открытый исходный код, легко модифицировать.
  • ✦Стильный адаптивный интерфейс в духе K-Pop.
  • ✦Бесконечная реиграбельность благодаря ИИ.

Минусы

  • ✦Требуется активный API-ключ (OpenAI/Anthropic).
  • ✦ИИ может иногда выходить из роли (галлюцинировать).
  • ✦Оптимизировано для ПК/веб (пока нет мобильного приложения).
  • ✦Первая загрузка может быть долгой в зависимости от ИИ.
